## ✨ ميزات مقترحة (New Features)

### 1. 📂 مستعرض ملفات مدمج (Built-in File Browser)
بدلاً من زر "اختر مجلد النماذج"، اعرض مستعرض ملفات داخل التطبيق نفسه Mock File Explorer (شبيه بـ Windows Explorer) يسمح بالتنقل بين المجلدات واختيار القوالب بصرياً.

### 2. 🎨 واجهة تحرير القوالب (Template Editor)
محول WYSIWYG بسيط يسمح للمستخدم:
- إضافة/إزالة Placeholders
- تغيير لون النص وحجمه
- إضافة جداول وصور
- حفظ القالب المعدل

### 5. 📋 سجل المستندات المولدة (Generation History)
اعرض قائمة بآخر المستندات التي تم إنشاؤها مع تاريخ ووقت واسم القالب، وزر لفتحها مباشرة.

### 6. 🖼️ Preview مصغر للمستند النهائي
**الملف:** `MainWindow.xaml`
بدلاً من TextBox نصي، اعرض Preview بصري (Image / PDF preview) يظهر كيف سيبدو المستند النهائي قبل الطباعة.

### 8. 🌐 دعم Metadata للقوالب
ملف JSON بجانب كل قالب يصف:
- وصف القالب
- الحقول المطلوبة مع تعليمات بالعربية
- مثال على التعبئة

### 9. ⚡ اختصارات لوحة المفاتيح (Keyboard Shortcuts)
- `Ctrl+N`: إنشاء مستند جديد
- `Ctrl+O`: فتح مجلد
- `Ctrl+P`: طباعة
- `Ctrl+C`: نسخ النص
- `Ctrl+Z`: تراجع
- زر F1: تعليمات
### 13. 📊 إحصائيات (Statistics)
أظهر عدد المستندات التي تم إنشاؤها، عدد القوالب، وقت الاستخدام.
